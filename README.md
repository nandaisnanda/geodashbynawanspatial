# 🌍 GeoDash

**GeoDash** is a modern geospatial dashboard application built using **React**, **Vite**, **Supabase**, and **Tailwind CSS**. It enables interactive visualization and analysis of geospatial data, offering fast performance and clean UI for real-time insights.

## 🚀 Features

- 🗺️ Interactive map with geospatial overlays
- 📊 Dynamic dashboard components (charts, tables, filters)
- 🔐 User authentication & role-based access (via Supabase)
- 🌐 Real-time data fetch and sync
- 📱 Responsive design with Tailwind CSS
- ⚡ Blazing-fast frontend with Vite

## 🛠️ Built With

- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Supabase](https://supabase.com/)
- [Leaflet](https://leafletjs.com/) or [Mapbox](https://www.mapbox.com/) (optional, depending on your mapping tool)
